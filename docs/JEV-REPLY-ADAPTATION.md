# 回复说明与口吻改写

参考项目：https://github.com/shengjidaguai-china/goutoujunshi-jev-chat

参考版本：`d19fd84305b5baa2f4b0f1147f177b163fef70a0`，MIT，Copyright (c) 2026 powerycy。
借鉴 `integrations/jev_mac/pipeline.py` 的候选 `text / reason / tradeoff` 和基于本人原话改写的原则。
许可证随键盘扩展打包为 `JevChatLicense.txt`。没有引入其平台窗口捕获、独立策略服务、额外排序请求或运行时依赖。

在现有「分析这段聊天」流程中，一次请求同时返回分析、对方状态、三条回复及理由、代价。
兼容旧接口返回的字符串回复；未返回的说明不编造。仅回复正文可以点选上屏。

成功结果提供「更像我」按钮。每次明确点击最多发起一个改写请求，仅以当前确认为「我」的消息作为口吻样本。
样本不足时要求使用自然口语。保留原分析与对方状态，只更换候选；不新增时间、地点或承诺。
改写期间不能重复请求或点选旧候选。取消、网络失败或无效候选都恢复原结果；切换聊天作废旧回调。

本次不改变手动输入上下文的六至八条回复流程，不自动请求 AI，不自动发送，不写人物记忆。

验证：Foundation 回归覆盖结构化候选、旧格式、说明对齐、改写准入、失败恢复、取消和过期回调；UIKit 回归覆盖说明展示、正文插入和明确按钮动作。
CI 编译与模拟器测试不等于真机端到端通过。模型口吻质量与重签后的实际界面仍需手机验证。
